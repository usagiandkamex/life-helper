# Life Helper

GitHub Copilot SDK を使った、**自分専用（GitHub アカウント `usagiandkamex`）のプライベート用サポートチャット**です。
ふるさと納税・ライフプラン・NISA などお金の相談、日々の調べもの、定期チェック（オートメーション）に使います。
会話・覚えたこと・ノートは Azure Files 上の Markdown に蓄積され、使うほど自分の状況を踏まえて答えられるようになります。

> お金に関する結果はすべて**目安**です。専門家（税理士・FP）の助言や投資助言ではありません。

## 主な機能

| 機能 | 内容 |
|---|---|
| チャット | Copilot SDK（`mode="empty"`）で回答。切断されても自動再接続して続きを受信（ACA の 240 秒制限対策）。画像・テキスト・CSV・PDF をその会話だけの資料として添付・貼り付けできる。回答中も追加で送信でき、「すぐに送信」（回答中の内容に反映）・「あとで送信」（回答後に順に回答。取り消し可）・「中断」を選べる |
| 蓄積 | 会話は Copilot のセッション永続化で再開。覚えたことは `memories/`、ノートは `notes/`、資料は `docs/`（Markdown）。プロフィールは毎回反映 |
| 検索 | Copilot の組み込みツール（`grep`（GPT 系モデルでは `rg`）/ `glob` / `view`）で知識ベースを検索（独自 DB・ベクトル検索なし） |
| 並行調査・調査委任 | 1 つの目的でいくつものキーワード・候補を調べるときは、独立した読み取り（`view` / `grep` / `web_fetch`）を 1 回の回答でまとめて実行して待ち時間を減らす。まとまった調べものは、読み取り専用の調査エージェント（`task`）に 1 回の回答で最大 6 件まで切り出して任せられる（前面実行のため 1 件ずつ順番に処理。チャット・オートメーションの両方） |
| お金の計算 | ふるさと納税の上限目安、ライフプラン、積立シミュレーション、譲渡益課税の目安（計算は決まった式で実行） |
| 資産 | 証券会社 CSV（SBI / 楽天）の取り込み、保有銘柄の数量・取得額の編集（積立・買い増し分の加算）、Yahoo Finance の前日終値で株価更新（日本株・米国株、無料・API キー不要の非公式 API。米国株は USD/JPY で円換算）、投資信託は投資信託協会の投信総合検索ライブラリーから基準価額を取得（全運用会社に対応。ファンド名が一致すれば自動で紐付け。予備として楽天投信投資顧問・大和アセットマネジメントの公式 CSV、どれにも当てはまらなければ手入力） |
| オートメーション | チャットの指示を決めた周期で実行（ACA ジョブが 15 分ごとに確認、1 回の実行時間は既定 20 分・設定で最大 60 分。「今すぐ実行」もアプリからジョブを起動して実行）。結果はアプリ内に記録し、チャットにも「会話」設定どおり（毎回新しい会話 / 同じ会話に続ける）読み取り専用の会話として表示。GitHub Issue 通知は指定したものだけ |
| コネクタ | 楽天ウェブサービス（楽天市場・楽天トラベル・楽天ブックス・楽天Kobo・楽天GORA・楽天レシピの検索。1 つのアプリ登録で 6 つの API を使う）など。API キーは Azure のシークレットだけに保存し、モデル・定義・履歴には出さない |
| ブラウザ | コンテナ内のヘッドレス Chromium（Playwright）で、JavaScript で表示するページの本文・リンク・表を取得。クリック・検索語の入力・スクリーンショットに対応（オートメーションでは「ブラウザ」を選んだものだけ） |

## 構成

```
ブラウザ ── GitHub OAuth ──> Azure Container Apps（最小 0 / 最大 1）
                               └ FastAPI + Copilot SDK ── GitHub Copilot（usagiandkamex のサブスクリプション）
                               Azure Files (/data): Copilot のセッション状態、知識ベース（Markdown）、アプリの状態
ACA ジョブ（15 分ごと・「今すぐ実行」）── オートメーションを実行 ──> GitHub App で Issue 通知（指定したものだけ）
GitHub Actions ── PR で CI ──> main にマージ ──> CI 合格後に OIDC で Azure へ自動デプロイ
```

| ディレクトリ | 内容 |
|---|---|
| `app/backend` | Python 3.12 + FastAPI + `github-copilot-sdk` |
| `app/frontend` | React + Vite + TypeScript（ビルド成果物を FastAPI が配信） |
| `infra` | Bicep（Container Apps とスケジュールジョブ、Azure Files、ACR Basic、マネージド ID、Log Analytics、予算アラート） |
| `scripts` | CI/CD の設定 |
| `.github` | CI / Deploy ワークフロー、PR テンプレート、Dependabot |

使わないもの: Azure OpenAI、Cosmos DB、ベクトル検索、Key Vault、Entra ID によるアプリのログイン。

## 安全のしくみ（要点）

- ログインできるのは GitHub ユーザー ID `134019422`（`usagiandkamex`）だけ。GitHub トークンは Cookie に入れず、暗号化して Azure Files に保存（ジョブと共有）。
- Copilot の組み込みツールは `view` / `grep`（GPT 系モデルでは `rg`）/ `glob` / `web_fetch` / `skill` / `task` だけを許可（シェルと組み込みのファイル書き込み `create` / `edit` / `apply_patch` は不可）。
  権限ハンドラと `pre_tool_use` フックの二重チェックで、読み取りは知識ベース内だけ。
- `task` で起動できるのはアプリが定義した調査エージェント（読み取りと `web_fetch` だけ。書き込み・ブラウザ・コネクタ・さらなる `task` は不可）のみで、背景実行は拒否、モデルや推論量の指定は取り除き、1 回の回答で 6 件まで。調査エージェントのイベントは回答そのものとは切り離して扱う。オートメーションは自分の担当エージェントのアイドルだけで終わるので、サブエージェントのアイドルで打ち切られない。
- 知識ベースへの書き込みはアプリの専用ツール（`write_knowledge_file` / `edit_knowledge_file`）だけで行い、書き込めるのは `memories/`・`notes/`・`plans/`・`INDEX.md` だけ。
  チャットでは既定で読み取り専用で、書き込みのたびに変更内容（差分）を表示し、利用者が「承認」したときだけ保存する（10 分応答がなければ保存しない）。
- `web_fetch` は外部の http/https ならドメインを問わず参照できる。内部宛先（localhost・プライベート IP・メタデータなど、DNS の解決先も確認）、
  API キーを URL に含むサービス（コネクタ専用）、機微情報・秘密情報を含む URL は拒否（`netguard.py`）。
- ブラウザの通信はすべてアプリ内の中継プロキシを通り、リダイレクト先やページ内の通信も含めて内部宛先へは接続しない。
  パスワード・カード情報の欄、ログインフォーム、機微情報の入力は拒否。ページは回答ごとに閉じる。
- マイナンバー・口座番号・カード番号・パスワードはファイルに保存しない。
- API キー・トークンはツール結果・エラー・ログから自動でマスク。
- ログアウトするとサーバー側でセッションを失効（コピーされた Cookie も無効）。
- `main` への直接 push・force push は行わず、PR の CI 合格後に squash マージする。デプロイは OIDC で、Azure の資格情報を GitHub に保存しない。
