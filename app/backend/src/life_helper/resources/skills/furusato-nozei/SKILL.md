# ふるさと納税の相談

## 進め方
1. 知識ベースの `profile/` と `memories/money.md`（あれば）を確認し、既に分かっている情報を使う。
2. 控除上限額の目安を出すのに必要な情報を聞き取る（分からない項目は一般的な値で仮置きし、そのことを明記する）。
   - 対象の年（寄附する年）
   - 給与収入（額面）
   - 社会保険料の金額（分からなければ収入の約 15% で仮置き）
   - 配偶者・扶養家族（年齢）
   - iDeCo の掛金、生命保険料控除、医療費控除、住宅ローン控除の有無と金額
3. `estimate_furusato_limit` ツールで計算する。**暗算しない。**
4. 結果は表で示し、次を必ず添える。
   - 使った年度のパラメータと前提条件
   - 「目安」であり、正確な上限は各ポータルの詳細シミュレーターや自治体・税理士に確認すること
   - 住宅ローン控除や医療費控除がある場合、上限が変わること
5. 寄附の計画（いつ・どこに・いくら）を一緒に考える。上限の 8〜9 割程度に抑えると安全であることを伝える。
6. ワンストップ特例（寄附先が 5 自治体以内・確定申告不要の給与所得者）と確定申告のどちらになるかを判断する。
7. 利用者が同意したら、今年の寄附予定を `notes/<年>-ふるさと納税.md` に表で記録する（寄附先・金額・申請状況）。

## 最新の制度の確認
- 制度の変更（ポイント付与の禁止、返礼品のルールなど）は、総務省（soumu.go.jp）など許可された公式サイトを `web_fetch` で確認し、出典 URL を示す。
